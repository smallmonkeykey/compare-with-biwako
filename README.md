# compare-with-biwako

琵琶湖と東京都23区の面積を比較できるアプリです。
ぜひ琵琶湖の大きさを身近に感じてください✨

# インストール

npmをインストールします
`npm install -g compare-with-biwako`
または
`npx compare-with-biwako`

# 使い方

## 区を選んで比較する

`compare-with-biwako`
比較したい区を選択します

## クイズモード（--quiz または -q）

`compare-with-biwako --quiz`
または
`compare-with-biwako -q`
ランダムで区が選ばれ「この区は琵琶湖の何倍？」というクイズが出題されます！

## 区を指定で比較する

`compare-with-biwako 渋谷区`
のように直接指定することもできます。
例えば渋谷区の場合、渋谷, 渋谷区, shibuya, shibuya-ku と入力することが可能です。
